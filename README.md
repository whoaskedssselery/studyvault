# studyvault

База знаний студента: конспекты, материалы, ссылки и заметки в одном месте.

## Статус

Готова первая локальная демоверсия фронтенда на React 19 + TypeScript + Vite. Сервер пока не подключён.

## Быстрый старт

```sh
cd frontend
npm ci
npm run dev
```

Библиотека, поиск, редактор конспектов, комментарии, оценки, избранное, модерация, профиль и демонстрационные вход/регистрация. Данные сохраняются в браузере. Пароли не сохраняются; авторизация имитируется.
