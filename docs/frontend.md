# Фронтенд StudyVault

Рабочая локальная демоверсия для презентации и скриншотов отчёта. Не подключена к серверу. Регистрация, вход и права модератора имитируются; пароли не сохраняются и не проверяются. Не вводите настоящие пароли или персональные данные.

## Запуск

Нужен Node.js 20.19+ или 22.12+.

```powershell
cd D:\spo2\studyvault\frontend
npm ci
npm run dev
```

Открыть адрес из терминала, обычно http://127.0.0.1:5173. Уже запущенный сервер доступен по этому адресу.

```powershell
npm run build           # TypeScript + production-сборка
npx playwright install chromium
npm test                # основные сценарии, desktop/mobile, скриншоты
```

## Что работает

- Библиотека, поиск по названию, содержимому и тегам, предметы, семестры, тип материала, сортировка, карточки/список.
- Страница конспекта, оценки 1–5, комментарии и избранное.
- Tiptap: текст, заголовки, полужирный, курсив, списки и код. Создание, сохранение и повторное редактирование черновиков.
- PDF/PNG/JPEG/WebP: до 2 МБ на файл и до 3 файлов, скачивание из страницы материала. Сохранение в localStorage ограничено квотой браузера; при переполнении показывается ошибка, запись не считается успешной.
- Отправка материала на модерацию, одобрение и отклонение с причиной. Отредактированный материал проходит проверку заново.
- Деморегистрация, вход, выход, профиль и рейтинг студентов.
- Мобильная версия и быстрый поиск по Ctrl+K / Cmd+K.

Демоаккаунт Алексея открыт по умолчанию. После выхода кнопка «Войти в демо» открывает его снова. Очередь модерации доступна этому аккаунту. Вход с email ранее созданного демоаккаунта принимает любой демонстрационный пароль длиной от 8 символов.

## Архитектура и следующий этап

React 19, TypeScript, Vite, TanStack Router и Query, Tiptap, Lucide, собственные адаптивные CSS-стили. `src/data.ts` содержит типы, демонстрационные данные и асинхронный `repository`. `src/main.tsx` — страницы и компоненты. Текущий адаптер нужно заменить вызовами API, а операции записи — серверными мутациями TanStack Query. JSON редактора соответствует формату Tiptap из `db/schema.dbml`; `text` нужен для поискового индекса.

**Нет настоящей авторизации, загрузки в MinIO, Meilisearch и обмена данными между пользователями/устройствами.** Права нужно проверять на сервере. Демоограничения фронтенда не являются защитой.

Схема `db/schema.dbml` пока не описывает комментарии, оценки, избранное и модерацию. Для ТЗ понадобятся:

- `comments(id, note_id, user_id, body, created_at)`;
- `note_ratings(note_id, user_id, value)` с уникальностью пары и целой оценкой 1–5;
- `note_bookmarks(note_id, user_id, created_at)`;
- статус публикации и причина отклонения у `notes`, роли у `users`;
- общие/публичные материалы: текущие subjects и tags привязаны к пользователям; нужно определить правила доступа.

Предлагаемые API: `/auth/register`, `/auth/login`, `/auth/refresh`, `/auth/logout`, `/users/me`; `/notes` с поиском и фильтрами; `/notes/{id}`; `/notes/{id}/comments`, `/rating`, `/bookmark`, `/submit`; `/moderation/notes` и `/moderation/notes/{id}/decision`; `/attachments`; `/leaderboard`. Это предложение для согласования с бэкендером, не существующий контракт. Когда будет OpenAPI, можно добавить `openapi-typescript` и `openapi-fetch`.

Рейтинг считается по сохранениям, комментариям и оценкам. Начальные рейтинги, счётчики чтений и содержимое материалов демонстрационные; счётчик чтений не обновляется по реальным просмотрам. Самостоятельные предметы, граф связей и wiki-ссылки пока не реализованы. Первую сборку стоит разбить на лениво загружаемые страницы, особенно редактор, перед production-развёртыванием.

Для сброса демоданных удалите ключи `studyvault.database.v1` и `studyvault.session.v1` в хранилище сайта через DevTools. Это удалит локальные публикации и демоаккаунты.
