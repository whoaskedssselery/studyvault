# StudyVault — комплект для сдачи

Проверено 23 октября 2026. Готовый сайт работает с настоящим API, базой PostgreSQL, поиском Meilisearch, файлами RustFS и локальной почтой Mailpit. Учебный вариант index.html + mock.json сохранён отдельно.

## Как открыть сайт

1. Запустить Docker Desktop и дождаться Engine running.
2. Дважды нажать **start.cmd** в корне репозитория. Либо выполнить `./start.ps1` из PowerShell.
3. Открыть http://localhost:5173/?mode=api. При первом запуске собираются образы; повторный использует кэш и сохранённую базу.

Node.js на компьютере для полного сайта не нужен. Исходники: [репозиторий StudyVault](https://github.com/whoaskedssselery/studyvault). Подробная [инструкция запуска](https://github.com/whoaskedssselery/studyvault/blob/main/docs/frontend.md).

Пароль задаётся SEED_PASSWORD при первом заполнении базы. Изменение переменной после seed не меняет уже созданные аккаунты. Для новых регистраций письма находятся на http://localhost:8025/.

## Что показать преподавателю за 5 минут

1. Гостем открыть библиотеку, выбрать предмет, найти SQL через Ctrl+K и открыть конспект.
2. Войти студентом, оценить чужой материал, оставить комментарий и добавить его в избранное.
3. Создать конспект, выбрать общий предмет, сохранить, прикрепить PDF и отправить на проверку. Показать предупреждение при уходе с несохранённым текстом.
4. В другом окне войти модератором, прочитать заявку и одобрить её. Для отклонения требуется причина; свой материал модератор не рассматривает.
5. Обновить гостевую библиотеку и показать публикацию. Переключить тёмную тему и открыть мобильный вид.

## Готовые функции

Библиотека, поиск по тексту и фильтры, авторы и рейтинг, чтение и скачивание; регистрация, вход и восстановление сессии; подтверждение почты и сброс пароля; профиль, смена пароля и удаление аккаунта. Личные конспекты с редактором, тегами, предметами и файлами; публикация и модерация; комментарии с редактированием, оценки и избранное.

Добавлены окно быстрого поиска, панель активности своих материалов, выбор предметов, справка, меню пользователя, тёмная тема, мобильная версия и защита несохранённого текста. Редактор и демоверсия загружаются отдельно: начальный JavaScript библиотеки — 423 117 байт вместо прежних примерно 899 КБ. Замер записан в capture.json.

## Что сдавать

Исходный проект — репозиторий, ветка main. Вклад Frontend для требования «index.html + mock.json» — папка deliverables/frontend. Скриншоты и этот отчёт — docs/submission. Для просмотра учебного HTML без Docker достаточно Node.js и команды `node serve.mjs --port 4174` из его папки; адрес http://localhost:4174/?mode=demo.

База и файлы сохраняются в Docker volumes. После показа остановить сервисы можно командой `docker compose --profile app --profile web stop`.
