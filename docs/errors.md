# Коды ошибок

Каждая ошибка API приходит в формате [RFC 7807](https://www.rfc-editor.org/rfc/rfc7807) с типом
`application/problem+json`:

```json
{
  "type": "https://github.com/whoaskedssselery/studyvault/blob/main/docs/errors.md#not_found",
  "title": "Not Found",
  "status": 404,
  "detail": "note not found",
  "code": "not_found",
  "request_id": "3f9a1c2b7d4e5a60"
}
```

- `code` стабилен: по нему клиент выбирает поведение. `detail` написан для человека и может меняться.
- `type` ведёт сюда, на раздел с кодом.
- `request_id` совпадает с заголовком ответа `X-Request-ID`. По нему нужную строку находят в логе сервера.

Чужие и несуществующие объекты неотличимы: оба дают `not_found`.

## validation_failed

**400.** Неверные входные данные: пустое или слишком длинное поле, неизвестное поле в теле, лишние данные после JSON,
тело больше 1 МБ, неправильный id или курсор. В `detail` сказано, что именно не так.

## unauthorized

**401.** Нет заголовка `Authorization: Bearer ...`, токен неверный или просрочен (access-токен живёт 15 минут), либо
аккаунта, на который выдан токен, уже нет. Клиенту стоит обновить токен через `POST /v1/auth/refresh` и повторить запрос.

## invalid_credentials

**401** при входе: неверная почта или пароль. **403** при смене пароля: неверен текущий пароль. Для смены пароля
выбран 403, чтобы клиент не принял ошибку за просроченный access-токен и не начал обновлять сессию.

## invalid_token

**401.** Refresh-токен отсутствует, просрочен или уже использован. Повторное предъявление использованного токена
считается кражей и закрывает все сессии пользователя. Нужен новый вход.

## not_found

**404.** Объект не найден или принадлежит другому пользователю. Тот же код получает неизвестный путь.

## method_not_allowed

**405.** У этого пути нет такого метода.

## email_taken

**409.** Почта уже зарегистрирована.

## tag_exists

**409.** У пользователя уже есть тег с таким именем.

## not_uploaded

**409.** Файл зарегистрирован через `POST /v1/attachments`, но сам файл ещё не загружен по выданной ссылке.

## limit_reached

**409.** Исчерпана квота пользователя: 200 предметов, 500 тегов, 50 файлов на заметку, 5000 файлов или 1 ГиБ суммарно.
В `detail` указано, какая именно. Освободите место удалением и повторите.

## rate_limited

**429.** Слишком много попыток входа, регистрации, обновления токена или смены пароля с одного адреса (по умолчанию
20 в минуту). Заголовок `Retry-After` говорит, через сколько секунд повторить.

## internal

**500.** Непредвиденная ошибка сервера. Подробности только в логе, клиенту они не отдаются; при обращении
назовите `request_id`.

## search_unavailable

**503.** Поиск временно недоступен. Остальное API работает.

## storage_unavailable

**503.** Хранилище файлов временно недоступно. Остальное API работает.
