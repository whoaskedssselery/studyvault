# Вклад Frontend в задание

Дата: 14 октября 2026. StudyVault — база знаний студента. Основой служит актуальный backend из main (PR №4 и №5, 06016a4) и его OpenAPI-контракт. Выполнен фронтенд и небольшой вклад в проверку интеграции; документы аналитика и презентация о деплое готовятся другими участниками.

## Результат для тимлида

- deliverables/frontend/index.html — рабочий интерфейс со встроенными CSS/JavaScript.
- deliverables/frontend/mock.json — отдельные фейковые данные для учебного задания.
- deliverables/frontend/README.md — просмотр и пересборка.
- docs/assignment-2/screenshots/ — скриншоты работающего интерфейса.
- docs/assignment-2/bug-reports.md — найденные проблемы, исправления и границы проверки.
- docs/frontend.md — запуск полного проекта на Windows.

Исходники React/TypeScript находятся в frontend/. Учебная сборка по умолчанию читает mock.json и сохраняет действия локально. Исходное приложение по умолчанию использует настоящий API. Переносимый HTML можно переключить на этот же интерфейс API через ?mode=api#/.

## Реальный API

Основная библиотека подключена к серверу: поиск и фильтры, курсоры, чтение материалов, авторы и рейтинг, комментарии и их редактирование, оценки и избранное. Гостю доступны опубликованные материалы и файлы.

Работают регистрация, вход/выход, refresh-cookie, подтверждение почты и повторная отправка с Retry-After, сброс пароля, изменение имени/факультета и пароля, удаление аккаунта. Одноразовые токены убираются из адреса до создания роутера и не сохраняются в браузерных хранилищах.

Редактор сохраняет Tiptap JSON, вид материала, описание, семестр, общий/личный предмет, теги. Доступны черновики, отправка и отзыв с проверки, повторная модерация после правок. Модератор одобряет или отклоняет материалы, снимает публикацию с причиной и управляет общими предметами.

Вложения PDF/PNG/JPEG/WebP проверяются до запроса: 3 файла по 2 МБ. Загрузка выполняется напрямую в RustFS по подписанной ссылке без Bearer-токена. Для локальных адресов настроен CORS хранилища. Ошибка назначения тегов после создания заметки не приводит к созданию дубликата при повторном сохранении.

Сохранены меню пользователя, тёмная тема, мобильный интерфейс. Служебные страницы API скрыты из основного меню.

## Проверки

- npm run package:submission — генерирует типы из текущего OpenAPI, проверяет TypeScript приложения и тестов, собирает production и переносимый HTML.
- 47 браузерных сценариев: деморежим, ошибки данных, меню/темы, файлы, полный клиент API на подставленных ответах, production-путь /v1, мобильный экран и API-режим переносимого HTML.
- 3 Node HTTP-теста прокси: маршруты, JSON, Bearer/cookie, cookie Path, курсоры и весь новый контракт.
- Отдельная сквозная проверка с настоящими Go API, PostgreSQL, Mailpit и RustFS в GitHub Actions: гостевая библиотека → регистрация → письмо и подтверждение → создание заметки → загрузка PDF → отправка на проверку → одобрение другим аккаунтом → чтение и скачивание гостем → удаление аккаунта.

Сквозной сценарий и все 47 клиентских сценариев прошли на cc7d883: [frontend CI](https://github.com/whoaskedssselery/studyvault/actions/runs/38567676010). Docker daemon локально не запущен, поэтому реальные сервисы проверены на runner GitHub, а не на этой машине.
