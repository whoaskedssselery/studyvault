# Переносимый фронтенд для сдачи

Для задания достаточно **index.html + mock.json** рядом. HTML содержит CSS и JavaScript; mock.json — отдельные фейковые данные. Это сборка того же React-приложения.

## Просмотр

В этой папке выполните:

```powershell
node serve.mjs --port 4174
```

Откройте http://localhost:4174/?mode=demo. Нужен Node.js; npm и Docker для учебного режима не требуются. Данные читаются из mock.json, изменения сохраняются локально в браузере.

Файлы можно разместить на обычном статическом HTTP-сервере. Hash-маршруты #/… работают без перенаправлений. Через file:// браузер блокирует fetch JSON, поэтому нужен HTTP-сервер.

## Настоящий сервер

Для обычной работы с API используйте полный репозиторий и start.cmd или start.ps1 из его корня. Они поднимают весь сайт через Docker на http://localhost:5173/.

Этот HTML тоже можно подключить к API: http://localhost:4174/?mode=api#/. serve.mjs направляет /backend-api/* на http://127.0.0.1:8080/v1/*, передаёт cookie и переписывает Path refresh-cookie. Выбор mode сохраняется в браузере. Возврат к мокам — ?mode=demo#/.

## Пересборка

Из frontend/ полного репозитория: `npm run package:submission`. Сначала создаётся обычная production-сборка с отдельными частями JS, затем отдельная сборка для самодостаточного HTML.

Актуальная инструкция и материалы для показа: docs/frontend.md и docs/submission/README.md в репозитории.
