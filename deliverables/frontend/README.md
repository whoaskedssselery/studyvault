# Файлы для сдачи: роль Frontend

- `index.html` — самодостаточный интерфейс, CSS и JavaScript включены в файл.
- `mock.json` — отдельные фейковые данные: 5 пользователей и 10 материалов.
- `serve.mjs` — необязательный локальный HTTP-сервер для удобного просмотра.

Для сдачи достаточно **index.html + mock.json**. Они должны лежать рядом. Это сборка React-приложения, а не отдельная копия вёрстки.

## Посмотреть без npm

```powershell
cd D:\spo2\studyvault\deliverables\frontend
node serve.mjs
```

Открыть http://127.0.0.1:4173/. Для другого порта: `node serve.mjs --port 4174`.

Можно использовать любой статический HTTP-сервер или разместить эти два файла в одной папке на хостинге. Переходы работают через `#/…`, поэтому настройка перенаправления всех URL на index.html не требуется. Через двойной клик `file://` браузер обычно блокирует загрузку JSON — используйте HTTP-сервер.

Учебная библиотека работает без API: начальные данные читаются из mock.json, действия сохраняются в localStorage и не изменяют файл. В «Кабинете API» доступны настоящий вход, заметки, предметы, теги, поиск, граф и S3-файлы. Для него нужен работающий backend и прокси `/backend-api`; serve.mjs направляет `/backend-api/*` на `http://127.0.0.1:8080/v1/*`, передаёт Bearer/cookie и переписывает Path refresh-cookie с `/v1/auth` на `/backend-api/auth`. Сам сервер API запускается отдельно через Docker Compose согласно корневому README.

Используется системный шрифт. Внешние CSS/JS-файлы не требуются для работы собранного интерфейса.
